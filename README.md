A tiny Node program that writes one short text to `/output/entry.txt` — one line about the dumbest thing the entrant's own agent did today. Forty minutes of debugging, and the bug is in a file the agent itself deleted in minute three: concrete, believable, wince-worthy, with the punch in the last few words. 123 characters, deterministic, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts && cat ./out/entry.txt
```
